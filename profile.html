💡 가치관 & 개발 철학

화려한 도구의 유행에 휩쓸리기보다는 웹의 근간이 되는 HTML 시맨틱 마크업, 반응형 CSS 레이아웃, 모던 JavaScript의 비동기 및 이벤트 메커니즘을 철저하게 체득하여 사용자에게 가장 빠르고 안정적인 웹 경험을 제공합니다.

  • 사용자 중심 사고: 접근성과 웹 성능 지표(Core Web Vitals)를 지속적으로 측정하고 개선합니다.
  • 지속 가능한 코드: 명확한 네이밍과 모듈화로 동료 개발자가 읽기 쉬운 클린 아키텍처를 추구합니다.
  • 기록과 공유: 문제를 해결한 과정과 배운 점을 블로그 글로 아카이빙하여 커뮤니티와 함께 성장합니다.
